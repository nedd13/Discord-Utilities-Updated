# 🛠️ Discord Utilities Extension

A lightweight, clean browser extension designed to enhance your Discord web experience with built-in productivity tools. Generate dynamic timestamps, custom color codes, and markdown formatting instantly with an integrated sidebar overlay.

---

## ✨ Features

- 🕒 **Timestamp Generator:** Easily pick dates and times to generate dynamic Discord relative tags (`<t:1672531200:R>`) that automatically adjust to every user's local timezone.
- 🎨 **Color Picker:** Select custom colors, grab HEX/RGB values, and easily format colored text blocks.
- 📝 **Markdown Formatter:** Apply headers, code blocks, blockquotes, and spoilers with single-click shortcuts straight into your chat box.
- 💻 **Native Discord Styling:** Designed using Discord's signature theme (`#1E1F22`, `#5865F2`, `gg sans`) for a seamless visual experience.

---

## 🚀 Installation Guide

Since this extension is currently loaded manually, follow these simple steps to install it in Chromium-based browsers (**Chrome**, **Brave**, **Edge**):

1. **Download or Clone the Repository**
   - Click the green **Code** button above and select **Download ZIP** (or clone the repository using `git clone`).
   - Extract the `.zip` file to a location on your computer.

2. **Open Extensions Settings**
   - In your browser's address bar, navigate to:
     - **Chrome:** `chrome://extensions/`
     - **Brave:** `brave://extensions/`
     - **Edge:** `edge://extensions/`

3. **Enable Developer Mode**
   - Toggle the **Developer mode** switch in the top-right corner of the Extensions page.

4. **Load the Extension**
   - Click the **Load unpacked** button in the top-left corner.
   - Select the extracted folder containing `manifest.json` and project files.
